# 真实素材示例

此目录当前只包含说明，**没有用户的 MOV 原片或 GIF 成品**。README 中的三张配图为功能/流程/目录规则说明，不是实际转换结果。

补充演示素材前，先确认该素材允许在公开 GitHub 仓库中提供下载，并允许 README 展示。不要把历史转换报告里出现的表情名称等同于已获得公开许可。

建议每个示例独立保存：

```text
examples/
└── heart/
    ├── source.mov
    ├── source-cover.png
    ├── 120gif/比心.gif
    ├── 220gif/比心.gif
    ├── 330gif/比心.gif
    ├── preview-on-backgrounds.png
    └── ATTRIBUTION.md
```

上面是未来结构示例，文件当前尚未创建；不在主 README 中添加指向不存在媒体的图片链接。操作步骤与嵌入示例见 [媒体指南](../docs/MEDIA.md)。
